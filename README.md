# 🏆 MakeX Inspire 成绩统计系统

面向 MakeX Inspire 队伍训练的**本地化成绩管理与统计工具**（纯静态网页，GitHub Pages 部署）。

所有数据默认保存在本地浏览器（localStorage / IndexedDB），可通过「后台 → 数据迁移」导出 / 导入备份或跨设备同步。

## ✨ 主要功能

- **集训管理**：创建集训、录入模拟赛 / 正赛记录、最佳成绩概览与排名
- **任务管理**：配置任务满分与「目标档位」（满分前提用时目标），支持全局 / 个体目标设定
- **个人成绩卡**：按 模拟练习 / 自主训练 / 整合 查看个人成绩与每项当前目标
- **自主训练**：学生独立录入练习成绩（得分默认满分、自动记录时间），可导出 CSV
- **成绩统计与教务**：统计页、班级 / 学员管理、数据迁移与开发者工具

## 🚀 本地测试 / 运行

纯静态网页、无构建步骤。任选一种方式即可本地预览（推荐方式 B，保证 localStorage / IndexedDB 等本地存储行为与线上 GitHub Pages 一致）：

**方式 A：直接双击打开**
双击 `index.html`（或以 `file://` 打开任意页面）即可使用。注意：部分浏览器对 `file://` 下的本地存储策略不同，若发现数据不互通 / 异常，请改用方式 B。

**方式 B：本地静态服务器（推荐）**
在项目根目录任选其一：

```bash
npx serve .            # 打开 http://localhost:3000
# 或
python -m http.server  # 打开 http://localhost:8000
```

浏览器打开对应地址即可访问全站。测试要点：

- 首次建议从「工具中心」`index.html` 进入。
- 数据默认保存在本地浏览器，测试产生的数据可通过「后台 → 数据迁移」导出 / 导入备份。
- 评估报告「🖨 导出 PDF」基于浏览器打印，可在「👁 导出预览」视图先核对排版再导出。
- AI 生成评语需先在评估页完成 AI 接入配置，其余功能均可离线使用。
